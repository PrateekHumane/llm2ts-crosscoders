What Survives the Leap
from Language to Time Series?

A crosscoder analysis across 27 transformer layers discovering shared features between a pretrained language model (PT), a time-series-finetuned model (FT), and a randomly initialized baseline (RI). We find interpretable features that detect repetition, slopes, spikes, and periodic patterns — concepts that transfer from language to temporal forecasting.

Method

1

Extract Activations

For each time series window (512 timesteps), run all three models. FT/RI use uniform-bin tokenization (512 bins). PT converts values to decimal text ("0.123 -0.456 ...") and mean-pools sub-token hidden states per timestep.

2

Train Crosscoder

A shared encoder (1024→2048→4096, TopK=64) is applied independently to each domain's normalized activations. Three separate decoders reconstruct each domain. 130k windows, DDP across 4×RTX 5090.

3

Categorize Features

Each feature is classified by which domains activate it: PT_FT (language transfer), FT_RI (convergent learning), Universal, etc.

4

Probe with WikiText

PT-involving features are probed on WikiText-103: feed text through PT, encode with wiki-specific normalization, find top-activating tokens. This reveals what each feature "means" in language.

Architecture

Each domain is encoded independently through the shared encoder. The sparse latent vectors (only 64 of 4096 features active) are then decoded by domain-specific decoders.

Loss Function
ℒ = ‖ x̂PT − xPT ‖² + ‖ x̂FT − xFT ‖² + ‖ x̂RI − xRI ‖² + α · ℒaux

α = 1/4. ℒaux is an AuxK auxiliary loss that revives dead features. TopK sparsity with k=64 (≈1.5% of 4096 features active per token). Decoder columns constrained to unit norm after each step.
