\section{The Pretrained Manifold: An Affinity for Transfer}
\label{sec:prior}

\subsection{A Linear Probe Reveals Latent Temporal Structure}
\label{sec:linear_decoding}

We ask: before any finetuning on time series, do pretrained language model representations already contain temporal structure? To test this directly, we train a single linear projection from a frozen pretrained model's hidden states to produce time series---with no paired text--time-series supervision and no modification to the model weights.

\paragraph{Method.} For each WikiText sequence, we extract hidden states from all 28 layers and concatenate them per timestep: $\mathbf{h}_{i,t} = [\mathbf{h}_{i,t}^{(0)}; \ldots; \mathbf{h}_{i,t}^{(27)}] \in \R^{D}$, $D = 28{,}672$. A per-timestep linear map $\hat{y}_{i,t} = \mathbf{w}^\top \mathbf{h}_{i,t} + b$ produces a predicted sequence $\hat{\mathbf{y}}_i \in \R^T$, z-normalized to zero mean and unit variance. Training uses EM-style nearest-neighbor matching: each prediction is matched to its closest real time series from GiftEval, and the map is optimized to minimize MSE to these assignments, with a spectral diversity penalty to prevent collapse.

\paragraph{Result.} The linear map produces 686 unique matches out of 10{,}000 real time series, spanning 14 of 20 temporal clusters. The map generalizes to held-out text (439 unique on unseen WikiText sequences). This is only possible if the pretrained representation space already contains directions whose projections resemble real temporal signals.

\paragraph{What creates this structure?} The result above could arise from multiple sources: the transformer architecture itself (residual connections produce smooth trajectories), the learned weights (pretraining compresses representations), or the input (natural text has sequential structure). We disentangle these by crossing model weights (pretrained vs.\ randomly initialized, same architecture) with input (WikiText vs.\ random tokens):

Only the combination produces diverse, high-quality temporal signals: the pretrained manifold provides the geometry, and text input drives diverse traversal of it.


\subsection{The Projected Dynamics Forecast Beyond the Context}
\label{sec:forecasting}

The linear decoding result shows shape-level similarity between projected hidden states and real time series. We test whether this extends to \emph{predictive} structure: given the first half of a time series, can a retrieved text projection forecast the second half?

\paragraph{Method.} We take 500 real time series from GiftEval and observe only the first 256 of 512 timesteps. Among 10{,}000 WikiText projections, we retrieve the one with lowest MSE on the observed first half. We then use that projection's second half as the forecast. The baseline is last-value carry-forward (repeating the final observed value).

\paragraph{Result.} Across all 500 queries, the retrieval-based forecast achieves MSE $= 1.91$ versus last-value's $2.27$ ($16\%$ lower). The retrieval wins in $37\%$ of cases; when it wins, the advantage is large (median $4\times$ lower MSE), because the retrieved projection captures trends and level shifts that last-value misses entirely. Figure~\ref{fig:forecasting} shows the best-case example from our evaluation set.

\subsection{Why the Manifold Enables Efficient Transfer}
\label{sec:math}

The linear decoding result has a direct implication for finetuning. Let $\mathcal{M} \subset \R^D$ denote the manifold of hidden-state trajectories produced by the pretrained model processing text. The linear decoding experiment shows that there exists a direction $\mathbf{w} \in \R^D$ such that the distribution of projected trajectories $\{\mathbf{w}^\top \mathbf{h}_t\}_{t=1}^T$ has significant overlap with the distribution of real time series $P_{\mathrm{TS}}$.

% then the finetuning objective doesn't need to reshape the entire
% representation space. It only needs to:
%   1. Identify which directions in M are TS-useful (low-rank selection)
%   2. Amplify those directions (adjust the readout)
%
% This is a low-rank transformation of the existing representation,
% rather than learning temporal dynamics from scratch.
%
% This explains why:
%   - LoRA with small rank captures most of the transfer (Section 4.1)
%   - FT compresses to lower effective rank than RI (Section 4.2)
%   - FT reuses PT's directions rather than finding new ones (Section 4.2)
%
% In contrast, a randomly initialized model has no such manifold.
% Its representations are near-isotropic (effective rank ~431).
% There are no privileged directions to select from, so finetuning
% must learn temporal structure from scratch across the full
% dimensionality of the representation space --- a harder optimization
% problem that converges to a less efficient solution.

If projections of $\mathcal{M}$ already approximate $P_{\mathrm{TS}}$, then adapting the model to predict time-series tokens autoregressively requires only identifying which directions in $\mathcal{M}$ are useful for temporal prediction and amplifying them. This is a low-rank transformation of the existing representation, rather than learning temporal dynamics from scratch across the full dimensionality of the space.


\subsection{Pretraining Creates Coherent Gradient Signal for the TS Objective}
\label{sec:curvature}

The manifold structure has a direct consequence for optimization. We compute per-example gradients of the TS loss at the pretrained versus random initialization, measuring whether individual training examples provide coherent or contradictory optimization signal.

\paragraph{Method.} For 30 individual TS sequences, we compute the gradient $\mathbf{g}_i = \nabla_\theta L_i$ restricted to layers 6--10 (78.7M parameters) at both initializations. We measure pairwise cosine similarity $\cos(\mathbf{g}_i, \mathbf{g}_j)$ across all example pairs, and the signal-to-noise ratio $\mathrm{SNR} = \|\bar{\mathbf{g}}\| / \mathrm{mean}(\|\mathbf{g}_i - \bar{\mathbf{g}}\|)$.

\begin{table}[h]
\centering
\caption{Per-example gradient structure at the TS loss surface. At PT initialization, different TS examples produce gradients that reinforce each other. At random initialization, gradients are nearly orthogonal and cancel upon averaging.}
\label{tab:gradient_alignment}
\small
\begin{tabular}{lcc}
\toprule
Metric & PT init & Random init \\
\midrule
Per-example gradient cosine & \textbf{0.58} & 0.04 \\
Gradient signal-to-noise ratio & \textbf{1.16} & 0.28 \\
Gradient norm (RMS) & 0.0040 & 0.0004 \\
\bottomrule
\end{tabular}
\end{table}

\paragraph{Interpretation.} At PT initialization, per-example TS gradients have cosine similarity 0.58---different time series sequences agree on which direction to adjust the weights. Batch averaging reinforces this shared signal. At random initialization, gradients are nearly orthogonal (cosine 0.04, consistent with random vectors in $\sim$78M dimensions), so averaging causes massive cancellation: the SNR drops to 0.28, meaning most of the per-example gradient signal is lost.

This coherence arises because the pretrained representations create consistent feature activations across different TS inputs. When the loss asks ``how should this weight change?'', the answer is similar regardless of which TS sequence is used, because the pretrained features impose a shared structure on the loss landscape. At random initialization, each example activates arbitrary features, giving contradictory signals.

The effect is layer-dependent: gradient norms at PT initialization are 3--19$\times$ larger than at random initialization, with the ratio increasing for deeper layers (where random weights scramble the signal most). This layer-wise gradient structure explains why mid-to-deep layers benefit most from pretrained initialization (Section~\ref{sec:dimensionality}).
