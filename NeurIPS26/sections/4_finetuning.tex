\paragraph{Catastrophic forgetting as geometric compression.}
Text$\to$FT collapses to effective rank 2.5 (from 150 in PT). Finetuning traded $\sim$140 text-useful dimensions for $\sim$12 TS-useful dimensions.

To examine how each model handles different temporal structures, we pass five synthetic inputs through all three models and visualize the hidden-state trajectories at Layer~8 via 2D PCA (Figure~\ref{fig:synthetic}). Each input is normalized and tokenized identically using uniform binning. We fit PCA independently per model--input pair, as the models occupy different regions of representation space. The first 5 positions are excluded to avoid the attention-sink artifact common in transformer first-position hidden states. Trajectories are colored by input phase (period 64) to reveal periodic structure.

\subsection{Interpreting the Transferred Features}
\label{sec:crosscoder_features}

% Crosscoder analysis: what do the shared features compute?

\paragraph{Method.} A crosscoder (shared encoder, per-domain decoders, TopK=64, 4096 latent dims) is trained on PT/FT/RI activations at each layer. Features are categorized by which domains activate them. PT-involving features are probed on WikiText-103.

\paragraph{Cross-domain features.} The top PT\_FT features encode \emph{structural temporal primitives} shared between text and time series:


\begin{table}[h]
\centering

\paragraph{Interpretation.} The transferred features detect \emph{computational patterns}---repetition, gradients, periodicity---not semantic content. These are primitives useful for any sequential prediction task. Language pretraining learns them because text also requires tracking repetition, change, and rhythm.
